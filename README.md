### Limitations
This code is built with the intention of timing different sorting functions.
The functions it is testing has not been optimized for the most efficient way to sort and filter. \
Warning:Because some of the sort functions include recursive methods, stack limit was set to 3000.\
If a sort function fails, please raise the recursion limit at your own risk.
